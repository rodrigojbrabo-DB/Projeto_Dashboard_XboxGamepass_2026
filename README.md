# Projeto_Dashboard_XboxGamepass_2026
🎮 Dashboard de Vendas – Xbox Game Pass (2026)
Projeto desenvolvido como entrega do curso Klabin – Excel e Power BI Dashboards 2026, ministrado pelo professor Felipe.
O objetivo foi construir um Dashboard de Vendas do Xbox Game Pass, analisando dados brutos e respondendo perguntas de negócio relevantes para a gestão.

📊 Sobre o Dashboard
Além das informações trabalhadas em aula, foram adicionadas novas análises extraídas diretamente dos dados brutos, incluindo:

Big Number com o total de cupons de desconto oferecidos (somando todos os planos),.

Gráfico de total de Subscriptions por mês.

Total de Subscriptions por plano.

Total de cupons de desconto por plano.

Big Number com o total geral de vendas do Xbox Game Pass.

🎯 Perguntas de Negócio Respondidas
O Dashboard foi construído para responder 9 perguntas de negócio, essenciais para apoiar decisões estratégicas:

Qual o faturamento total de vendas de planos anuais (considerando todas as assinaturas agregadas)?

Qual o faturamento total de vendas de planos anuais, separado por auto renovação e sem auto renovação?

Qual o total de assinaturas do EA Play Season Pass?

Qual o total de assinaturas do Minecraft Play Season Pass?

Qual o total de vendas de cada plano?

Qual foi o total de vendas em cada mês?

Qual foi o valor total de cupons de desconto concedidos?

Qual foi o total de cupons de desconto por plano?

Qual foi o total geral de vendas do Xbox Game Pass?

📘 Conclusão
Este projeto demonstra como a análise estruturada de dados pode gerar insights valiosos para decisões de negócio, especialmente em modelos de assinatura como o Xbox Game Pass.
A combinação de Excel e Power BI permitiu criar uma visão clara, objetiva e orientada a métricas.
